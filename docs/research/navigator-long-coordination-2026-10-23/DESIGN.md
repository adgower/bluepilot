# Local integral / actuator / fallback resolution

Authorized continuation of the report-local grade prototype; no device access or paired-source changes. Preserve1.20/0.97 and installed stop/creep behavior.

Root mechanisms: existing LongControl integrates error without knowing when Handoff intentionally caps propulsion; resumption qualifies by elapsed time rather than observed brake release; previous grade mapping immediately drops its offset on missing context. A blanket integral freeze during braking can deadlock grade release and is rejected. Nm is not acceleration and no torque-to-acceleration calibration will be invented.

Implement one explicit timestamped interface between moving-speed coordination and parent LongControl. Feedback includes generation/sequence, producer time, actual sent gas, requested gas, actual brake bit, and whether a deliberate release/ramp is limiting propulsion. Freeze only positive integral growth into that known cap, with positive intent and fresh same-generation feedback; permit negative error/unwinding and genuine braking. No integral rebasing/jumps, no arbitrary gain change. Default-off parity.

After an actual brake request, require three distinct fresh brake-torque samples <=4Nm spanning>=40ms before valid propulsion returns. Repeated cached samples cannot qualify. Waiting never expires into blind resumption: a1s moving release timeout requests disengagement and latches until inactive. The first500ms deadline was rejected by an original-command Alpha release retaining60–90Nm for~0.7s; independent settled OEM samples are zero, so the clear threshold is not loosened. The deadline is a fault boundary, not permission to drive against reported brake torque. Low-speed/stop/restart retain installed behavior below3m/s. Existing0.5m/s³ request-rise limit remains.

Separate finite pose freshness from static reference confidence. A lost static reference ramps the applied offset toward zero; stale/invalid pose or required actuator feedback cannot silently keep operating. Explicit fault/disengagement result is part of the interface, including immediate neutral longitudinal output in the local controller adapter. Epoch changes invalidate old feedback; re-entry requires a fresh off/on cycle. No automatic fault clearing while active.

Evidence plan: RED/GREEN contracts; saved58-segment provenance, OEM selected-state checks; full65,736actual Alpha command slots with timestamped feedback and native RX/timer ACC replay; parent-in-the-loop replay recomputing integral against frozen recorded response; bounded-response scenarios using measured release-delay ranges and actuator uncertainty. Logged actuator response is not counterfactual response. No claim that model passing establishes physical smoothness or road readiness. Any surviving software failures are reported by name; no integration/push/install in this task.
