Scope approved by the user's request: resolve the existing prototype's calibration integration, timing and release gaps locally; no device access, activation or CAN transmission. Carry validity, source/state/computation monotonic timestamps, target speed and model parameters. card uses that same CarControl packet; no separately arriving calibration topic or latest-packet join. Default/old messages are invalid and preserve baseline.
2. Timing: consumer rejects future, expired, incoherent or reordered controls/snapshots; target reconstruction uses producer target speed. Producer source age and receive-to-compute age are separate. Test the actual staged Cap'n Proto wire message and local IPC, including packet delay, drop, repeat and reorder. Logs cannot prove historical exact producer consumption; reconstructed snapshots in offline replay are explicitly labeled synthetic causal fixtures, while strict legacy messages must fall back.
3. Release: preserve an independent unmodified baseline state and constrain the mapped final command against that baseline through the existing final range/slew bounds. On invalidation/reversal, move to the nearest reachable baseline and block rearming while a final-output difference remains. No forced jump/reset to conceal a slew tail. Baseline motion can prevent a universal release-time guarantee under the existing rate limit; test and report that limit explicitly.
4. Selection: separate default-off parameter in staged paired sources; existing persistent tracking selection remains unchanged unless explicitly enabled. No parameter is written and no live tree is selected.

Distinguish local implementation/testing from production build, hardware and road validation.
